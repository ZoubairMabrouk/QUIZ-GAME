# Quiz Game Flutter

Client français responsive : téléphone et OTP SMS/WhatsApp, profil, portefeuille, création/jonction de salle, présence et état prêt, questions chronométrées, correction, classement et récompenses.

Voir `../docs/ETAPE_3.md` pour le lancement complet avec le backend et deux joueurs. Flutter 3.47.7 a été utilisé pour la validation. Le client nécessite l'API de ce projet ; `API_URL` est une constante de compilation passée via `--dart-define`.

Les sessions restent en mémoire. Le mode mock est annoncé visuellement et ne valide aucun numéro réel.
